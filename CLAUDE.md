# CLAUDE.md

## Design Context

This project is set up with [impeccable](https://impeccable.style) design context.

- **Register:** brand (portfolio — design is the product)
- **Strategy & principles:** see [PRODUCT.md](./PRODUCT.md) — users, purpose, brand personality (experimental & bold, sharp, systems-minded), anti-references, design principles, accessibility (WCAG AA).
- **Visual system:** see [DESIGN.md](./DESIGN.md) — colors, typography, components, layout, motion.

Before design work, read PRODUCT.md and DESIGN.md. The committed identity (dark near-black navy, cyan/electric-blue/mint neon accents, Space Grotesk + Manrope, glow shadows, float/pulse motion) is the brand — evolve and sharpen it rather than restyling from scratch.

Run `/impeccable` for the full command menu, or `/impeccable <command> <target>` directly.
